# Data Taxonomy & Classification Framework

## Role Hierarchy
- **Primary Tier:** Data Analyst, Senior Data Analyst, BI Analyst, Business Intelligence Analyst, BI Developer, Power BI Developer, Analytics Engineer.
- **Secondary Tier:** Data Engineer, Data Integration Engineer, ETL Developer, SQL Developer, Database Developer, Reporting Analyst, Reporting Developer, Data Visualization Analyst, Analytics Consultant, Data Operations Analyst.
- **Legacy Leverage Tier:** Oracle Developer, PL/SQL Developer, Oracle Database Developer, Database Analyst, SQL Server Developer, Database Engineer, ETL Developer.

## Geographic & Market Tiers
- **Priority 1 (Local & Citizenship):** Lima (Peru), Peru, Argentina.
- **Priority 2 (Spanish-speaking LATAM):** Chile, Colombia, Mexico, Uruguay, Ecuador, Costa Rica, Panama.
- **Priority 3 (International Remote):** United States, Canada, United Kingdom, Ireland, Europe, Global Remote.

## Language Strategy
- **Primary Language:** Spanish (High Accessibility).
- **Secondary Language:** English (Developing Accessibility / High Market Penetration).
