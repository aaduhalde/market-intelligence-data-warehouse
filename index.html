2. Staging

Deduplication, schema normalization & Parquet staging.

3. Staging DB

T-SQL Staging table landing zone in Azure SQL.

4. Data Warehouse

Star Schema model (Fact + Dimensions) transformation.

5. Analytics & BI

SQL Views, Matching Engine & Power BI Dashboards.

Core Business Rules & Features

BR-001: Deterministic Deduplication

Prevents duplicate postings using composite hash keys (`empresa + titulo + ubicacion + fecha`) and Watermarking.

BR-004: Skill Taxonomy Engine

Regex pattern matching against structured YAML rules (`config/skills.yaml`) to normalize unorganized job descriptions.

BR-020: Candidate Match Score

Calculates an accessibility index and match percentage between job offers and target candidate profiles.
